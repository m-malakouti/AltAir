# گزارش بررسی APIها — ۲۵ مهر ۱۴۰۵

بررسی روی سرور محلی `http://127.0.0.1:5279` و با درخواست واقعی انجام شد.

| بخش                   | نتیجه و شواهد                                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| سلامت سرور            | `/health` با HTTP 200 و `status:ok`                                                                                                                                  |
| بازار ارز و فلزات     | `/api/market/usd` پاسخ معتبر برای پارسر واقعی فرانت‌اند؛ ۱۶ نرخ، `fetchFailed:false`                                                                                 |
| رمزارز                | ۸ رمزارز از همان پاسخ بازار، معتبر برای پارسر واقعی فرانت‌اند                                                                                                        |
| جست‌وجوی شهر          | `/api/weather/cities`، نتیجهٔ تهران و اعتبارسنجی ساختار شهرها                                                                                                        |
| آب‌وهوای فعلی و ساعتی | `/api/weather/current`، داده و پیش‌بینی ساعتی معتبر برای پارسر فرانت‌اند                                                                                             |
| آب‌وهوای روزانه       | `/api/weather/day` برای روز جاری، پاسخ معتبر                                                                                                                         |
| آب‌وهوای تاریخی       | همان مسیر برای ده روز پیش، پاسخ معتبر و `historical:true`                                                                                                            |
| نتایج فوتبال          | کلاینت واقعی ESPN برای هر هفت لیگ و هر دو تاریخ؛ `partial:false`                                                                                                     |
| حساب آزمایشی محلی     | درخواست کد، تأیید کد، خواندن نشست و خروج موفق؛ پس از خروج HTTP 401؛ بدون ارسال پیامک یا ساخت پروفایل دائمی                                                           |
| گوگل                  | endpoint اطلاعات کاربر در دسترس و درخواست بدون توکن با HTTP 401 رد شد. ورود احراز هویت‌شده پیش‌تر توسط کاربر تأیید شده است؛ در این بررسی ورود تعاملی مجدد انجام نشد. |
| تشخیص اینترنت         | هر دو endpoint گوگل و Cloudflare با HTTP 204                                                                                                                         |
| نقشهٔ گوگل            | کلید Maps Embed تنظیم نشده؛ طبق تصمیم قبلی غیرفعال است و نمایش زنده تأیید نشده است.                                                                                  |
| مسیریابی نشان         | endpoint وضعیت سالم و `configured:false`؛ کلید وجود ندارد و کارت فعلی آن را فراخوانی نمی‌کند.                                                                        |

در شروع بررسی، سرور محلی خاموش بود. سرور اجرا شد و پس از اصلاح زیر، نسخهٔ جدید به‌صورت فرایند محلی بدون پنجره روی پورت 5279 روشن ماند. این کار سرویس Windows یا اجرای خودکار بعد از راه‌اندازی مجدد سیستم ایجاد نمی‌کند.

Open-Meteo در بخشی از درخواست‌ها HTTP 503 با پیام `The service is overloaded` برگرداند. درخواست‌های آب‌وهوا اکنون برای 502/503/504/429 فقط یک بار، در محدودهٔ مجموعاً ده ثانیه، تکرار می‌شوند. Retry-After بیش از دو ثانیه باعث تکرار فوری نمی‌شود. خطای ورودی و خطای پارس با تکرار درخواست پنهان نمی‌شوند.

نتیجهٔ اعتبارسنجی:

- ۳۱۰ تست فرانت‌اند موفق.
- ۹۲ تست سرور موفق، شامل ۴ بررسی جدید بازیابی خطای موقت.
- ۱۲ تست زنده موفق؛ پاسخ‌ها با پارسر واقعی فرانت‌اند بررسی شدند.
- TypeScript و ESLint تست زنده موفق.

تست زنده عمداً در اجرای معمولی تست‌ها غیرفعال است؛ درخواست واقعی به سرویس‌ها می‌فرستد و می‌تواند سهمیه مصرف کند. برای اجرای مجدد روی سرور Development محلی:

```powershell
$env:ALTAIR_LIVE_API_URL='http://127.0.0.1:5279'
npx.cmd vitest run features/integration/api-live.test.ts --reporter=verbose
Remove-Item Env:ALTAIR_LIVE_API_URL
```

نشست‌ها و کدهای ورود در گزارش چاپ نمی‌شوند. آزمایش زنده نتیجهٔ همان زمان است و تضمین پایداری آیندهٔ سرویس خارجی نیست. مجوزهای مرورگری، iframe پادکست و نمایش نقشهٔ بدون کلید با تست HTTP به‌تنهایی تأیید نمی‌شوند. ثبت پروفایل روی سرور و اعتبارسنجی ورودی آن در تست‌های سرور پوشش داده می‌شود؛ این بررسی حساب آزمایشی دائمی جدیدی نساخت.
