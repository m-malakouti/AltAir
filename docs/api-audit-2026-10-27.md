## اصلاح انجام‌شده

در `wxt.config.ts`، میزبان دقیق `https://castbox.fm` به `frame-src` افزوده شد. قبلاً فقط `https://www.google.com` مجاز بود و iframe پلیر Castbox مستقل از سلامت سرویس خارجی مسدود می‌شد. مجوز جدیدی برای دسترسی به داده‌های مرورگر اضافه نشده است.

## محدودیت‌های باقی‌مانده

- مبدأ `http://localhost:4179` هدر CORS مجاز دریافت کرد؛ `http://localhost:3000` دریافت نکرد. اگر پیش‌نمایش روی 3000 اجرا شود، این مسئله باید با افزودن مبدأ صریح توسعه حل شود؛ CORS عمومی نشده است. مجوز host افزونه از CORS پیش‌نمایش جداست.
- پیامک واقعی و کلید نقشه تنظیم نشده‌اند. موفقیت نشست محلی یا وجود OAuth client ID به معنی تأیید ورود واقعی نیست.
- سیاست دریافت تقاضامحور نوسان حفظ شده است؛ این بررسی قیمت‌ها را به فید لحظه‌ای تبدیل نمی‌کند. مجوز بازنشر در تنظیمات همچنان تأیید نشده است.
- نتیجهٔ Castbox تا پاسخ HTTP و اصلاح سیاست قاب تأیید شده؛ پخش صوت، سیاست‌های کوکی و رفتار نهایی در افزونهٔ نصب‌شده نیازمند بررسی تعاملی‌اند.

گزارش قدیمی `api-audit-2026-10-24.md` سابقهٔ همان روز است؛ پیکربندی و نتیجه‌های آن جایگزین بررسی فعلی نیستند.

## اعتبارسنجی تغییر

- هر ۱۱۹ تست بک‌اند و ۹۱ تست مرتبط افزونه پاس شدند؛ این تعداد، اجرای کامل تمام تست‌های افزونه نیست.
- ساخت Chrome MV3 موفق بود و مجازبودن میزبان دقیق Castbox در CSP خروجی بررسی شد؛ wildcard یا مجوز مرورگری تازه اضافه نشد.
- بررسی بازار بدون هدر مدیریت 403 و مشاهدهٔ وضعیت با Origin خارجی 404 داد؛ هیچ‌کدام سهمیهٔ نوسان را افزایش ندادند.
- قالب‌بندی فایل‌های تغییرکرده و `git diff --check` بررسی شدند.
