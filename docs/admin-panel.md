# پنل مدیریت محلی AltAir

آدرس: http://127.0.0.1:5279/admin

اجرا از ریشهٔ پروژه در PowerShell:

```powershell
$env:ASPNETCORE_ENVIRONMENT = 'Development'
dotnet run --project server/AltAir.MarketApi --urls http://127.0.0.1:5279
```

این نسخه مخصوص مدیریت محلی است. محیط Production، آدرس‌های غیر loopback، Host غیرمحلی و Origin خارجی رد می‌شوند. ثبت تنظیمات نیازمند هدر اختصاصی همان صفحه است. پنل ورود ادمین عمومی و نقش‌ها هنوز ندارد و نباید برای دسترسی اینترنتی به آن تبدیل شود.

## امکانات

- دریافت وضعیت پیکربندی بدون نمایش کلیدها؛ تنظیم‌بودن با سلامت واقعی اتصال متفاوت است.
- بررسی دستی سلامت بک‌اند، نرخ بازار و آب‌وهوای تهران. بررسی بازار از مسیر کش و سهمیهٔ فعلی سرویس عبور می‌کند.
- ذخیرهٔ فاصلهٔ دریافت، آستانهٔ قدیمی‌شدن و سقف ماهانه در `App_Data/admin-settings.json` با جایگزینی اتمی فایل.
- سیاست جدید در درخواست بعدی خوانده می‌شود؛ کش موجود و زمان انتظار قبلی دستکاری نمی‌شوند. آستانهٔ جدید با دریافت نرخ تازه اعمال می‌شود.
- سقف ماهانه همان شمارندهٔ حافظه‌ای سرویس فعلی است؛ با ری‌استارت صفر می‌شود و تضمین سقف صورتحساب ارائه‌دهنده نیست.
- ورود گوگل، فوتبال، رسانه و نقشهٔ داخل افزونه با برچسب دقیق «داخل افزونه / تست نشده» نمایش داده می‌شوند.
- تسک‌ها و اطلاعات گوگل در مرورگر هستند؛ فهرست حساب‌های موبایلی از مخزن همین سرور خوانده می‌شود.

## مسیرها

`GET /admin/api/overview` وضعیت و سیاست مؤثر را می‌دهد.
`POST /admin/api/settings` با JSON شامل `pollMinutes`، `staleAfterMinutes`، `maxRequestsPerMonth` و هدر `X-AltAir-Admin: 1` سیاست را ذخیره می‌کند.

کلیدهای Navasan/Neshan از پیکربندی امن قبلی خوانده می‌شوند و در پاسخ API پنل قرار نمی‌گیرند.

## کاربران

بخش کاربران، حساب‌های موبایلی همین سرور را از مخزن رمزگذاری‌شده می‌خواند؛ حساب‌های گوگل هنوز به بک‌اند متصل نیستند. نام، شماره موبایل و آخرین ارتباط نشست نمایش داده می‌شود. فعال یعنی ارتباط معتبر طی پنج دقیقهٔ اخیر؛ افزونهٔ قابل‌مشاهده هر دو دقیقه وضعیت را تازه می‌کند. خروج، انقضای نشست و ری‌استارت سرور سابقهٔ فعالیت نشست را حذف می‌کند؛ حساب ثبت‌شده باقی می‌ماند. فهرست هر دقیقه تازه می‌شود و مسیر آن /admin/api/users تحت محدودیت دسترسی محلی پنل است.
