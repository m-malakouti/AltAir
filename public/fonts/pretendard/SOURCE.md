# Pretendard

Unmodified Pretendard Variable 1.3.9 by Kil Hyung-jin (orioncactus).
Bundled for the ambient clock only; no remote font request is made at runtime.

- Project: https://github.com/orioncactus/pretendard/tree/v1.3.9
- Font: https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- License: SIL Open Font License 1.1, included in OFL.txt.

The default clock styling was checked against the public Chrome Web Store package
of Momentum 2.27.8: default Windows family Pretendard, weight 500, 152px desktop
size, 1.15 line height, -4px tracking, and a colon raised by 0.095em. Existing
Count Up animation and the Persian interface remain AltAir implementations.
